# Freitas-Brandao-Front

Base inicial do frontend do sistema de hospedagem digital.

## Tecnologias

- React
- Vite

## Como executar

```bash
npm install
npm run dev
```

Se o PowerShell bloquear o comando `npm`, use:

```bash
npm.cmd install
npm.cmd run dev
```

## Estrutura inicial

- `src/App.jsx`: tela inicial com contexto do projeto
- `src/styles.css`: estilos globais da base visual
- `src/main.jsx`: ponto de entrada da aplicacao
